# Campus Optics Lab Adventure

A short command-line choose-your-own-adventure about a student lost in the
campus optics lab on the night before a hackathon deadline. Choices can add
items to your inventory, which unlocks additional routes.

Run with Python 3:

```sh
python3 adventure.py
```

Enter the number beside a choice to continue, or enter `q` at any prompt to
quit.

Run the tests with:

```sh
python3 -m unittest -v
```
